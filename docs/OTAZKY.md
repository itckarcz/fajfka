# Otvorené otázky

Otázky pre účtovníka, daňového poradcu alebo pre nás. Claude Code sem zapisuje všetko, čo nevie isto. Po zodpovedaní dopíš odpoveď a dátum.

## Pre účtovníka / daňového poradcu
- [ ] Zaokrúhlenie DPH: raz za sadzbu v rekapitulácii, alebo po riadkoch? Na haléře, alebo na koruny?
- [ ] Zaokrúhlenie hotovosti u platiteľa DPH: ako zaobchádzať s rozdielom (riadok „Zaokrouhlení“ mimo DPH)?
- [ ] Presné znenie textu pri prenesenej daňovej povinnosti a či uvádzať kód CZ-CPA.
- [ ] Minimálne náležitosti zjednodušeného daňového dokladu – stačí naša šablóna?
- [ ] Náležitosti faktúry neplatiteľa (text o zápise v živnostenskom registri).
- [ ] Opravný daňový doklad pri storne – náležitosti (§ 45 ZDPH).

## EET (overiť v oficiálnej dokumentácii)
- [ ] Názvy a formáty polí správy podľa aktuálneho XSD.
- [ ] Čo presne musí byť na doklade (POK, ID jednotky, poradové číslo).
- [ ] Môže e-mail s dokladom odísť skôr, než príde POK (s textom o dodatočnej evidencii)?
- [ ] Ako funguje pilotný mesiac (január 2027)?

## Produkt
- [ ] Limit faktúr v tarife Zdarma.
- [ ] Doména a ochranná známka „Fajfka“.
- [ ] Právne texty (obchodné podmienky, GDPR) – kto ich skontroluje.
