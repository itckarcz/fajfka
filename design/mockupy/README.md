# Mockupy obrazoviek

Statické návrhy z plátna „Fajfka – návrhy obrazoviek“ (claude.ai). Každý súbor je jedna obrazovka.

- Mobil 390×844: `Main` (Domů), `Faktura-1-zakaznik`, `Faktura-2-polozky`, `Faktura-3-platba`, `Faktura-4-qr`, `Faktura-5-hotovo`, `Faktury`.
- PC: `PC-prehled`. Web: `Web`.

Pre Claude Code: ber z nich rozloženie, veľkosti, farby a české texty. Značky `<x-dc>`, `<helmet>` a skript `support.js` patria editoru plátna, do appky ich neprenášaj. Postav komponenty v Next.js a Tailwinde podľa `docs/DIZAJN.md`.

Ukážkové údaje (mená, sumy, Novák Instalace) sú vymyslené.
